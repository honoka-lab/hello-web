# 🌷 資産推移グラフ

2017年から2025年までの資産の推移をまとめた可視化プロジェクトです。  
家族の「成長」と「資産の歩み」を一緒に見守ることをテーマにしています。

---

## 📊 グラフの特徴
- **棒グラフ**：資産額（万円）
- **折れ線グラフ**：前月比の増減
- **配色**：家族みんなが見やすいように、やさしいピンクとミントグリーンでデザイン  
- **自動更新**：新しい月のデータを1行追加するだけでグラフが伸びます！

---

## 🛠 更新ルール
1. `index.html` の `assetData` に新しい月のデータを1行追加  
2. 変更を **Commit（保存）** する  
3. 数分後に Web ページが自動で更新  
   👉 [公開ページはこちら](https://honoka-lab.github.io/hello-web/)

---

## 💡 今後のアイデア
- 年ごとの集計や平均増加率の自動表示  
- 可愛いテーマ切り替え（春・夏・秋・冬）  
- 家族のイベントと資産推移を並べた「ライフトラック」表示
